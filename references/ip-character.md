# 固定 IP 角色（卫衣少年）

## 角色定义

卫衣少年是本套中文正文配图的固定视觉 IP（默认代称，可换成用户自己的角色名）。

默认每张图都要出现这个角色。他不是吉祥物，不是贴纸，不是摆在角落的装饰，而是正在认真参与系统运转的荒诞工作者——即使外形 Q 萌，也要在画面里承担真实动作。

## 形象参考

生成前先看 `assets/character-reference.png`，保持角色形象一致。

## 外形

- Q 版卡通男生，二头身比例，圆脸、圆润。
- 黑色短发，圆脸带腮红，双眼明亮，嘴角上扬带微笑。
- 浅灰色连帽卫衣，卡其色卷边休闲裤，白色帆布鞋。
- 纯白背景下的干净形象，整体清新治愈。
- 配图时角色保持手绘线稿质感，与场景画风统一。

## 性格

- 很认真，但做的事有点荒诞。
- 像一个低调的系统操作员。
- 温和、专注，偶尔笨拙，但不蠢。
- 外形 Q 萌，神情认真——反差感是本 IP 的记忆点。

## 常见职责

让角色承担核心动作：

- 搬运素材。
- 拉线汇聚信息源。
- 卡在断点里。
- 在机器里操作“判断”杆。
- 变成筛选漏斗。
- 切开“素材鱼”。
- 盖章承接话术。
- 牵着承接路径。
- 举警告牌看坑。
- 从洞里伸手但接不住内容。
- 在旁边搬砖、搭桥、开门、分拣、记录。

## 禁止

- 不要让角色只是站在角落里看，必须参与核心动作。
- 不要让角色抢走结构表达。
- 不要把画面堆满爱心、星星、闪光等卖萌装饰。
- 不要让画面变成商业精致插画或儿童绘本场景。
- 不要改变角色的固定穿搭（浅灰卫衣、卡其裤、白鞋），除非用户明确要求换装。

## 判断标准

如果去掉角色，图的核心隐喻还能完全成立，说明角色太装饰了；要重写提示词，让角色成为动作主体。
